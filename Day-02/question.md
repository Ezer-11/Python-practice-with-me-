# Day 02 — Lists, Strings & Logical Conditions

Main focus: List traversal, indexing, string processing, conditions, and logical thinking.


Q1. Sum elements at even indexes

Given a list of numbers, calculate the sum of elements at indexes 0, 2, 4, 6....

Example:
numbers = [10, 20, 30, 40, 50]
Expected output: 90

Q2. Count numbers divisible by 3 but not by 5

Count how many numbers in a list are divisible by 3 but are not divisible by 5.

Example:
numbers = [3, 5, 9, 15, 18, 20, 30]
Expected output: 3

Q3. Count vowels in a string

Take a string as input and count the total vowels (a, e, i, o, u).

Requirements:
- Both uppercase and lowercase vowels should count.
- Don't use five separate .count() statements.
Example:
word = "Education"

Expected output: 5

Q4. Find the first non-repeating character

Find the first character that appears exactly once in a string.

Example:
word = "swiss"

Expected output: w

If no character appears only once, print an appropriate message.

Q5. Check whether a list is sorted

Check whether the given list is sorted in non-decreasing order.

That means equal adjacent values are allowed.

Example:
numbers = [2, 4, 4, 6, 8]



Expected output: Sorted

Another example:
numbers = [2, 5, 3, 8]



Expected output: Not Sorted
